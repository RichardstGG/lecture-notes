## 架構決策（已與使用者確認）
- CLI 與 UI 獨立：UI 不 import core，只透過設定檔、`lec` 子指令（含 `--json`）、status.json/events.jsonl/run.json。
- 設定四層合併：default.toml → local.toml（本機）→ courses/<課名>.toml → 指令列。
- 麥克風預設 `default`；`lec devices --save` 寫入 local.toml。
- 課程範例 courses/examples/，`lec new 課名 --from UNIXops`。
- 引擎版本鎖 engines.lock；`--update`、`--lock`、同版本略過編譯、`--rebuild`、`--import-models`。
- LLM 一律用 Qwen3-8B。

## UI 可用的 CLI 介面（當時的契約，現況以程式碼為準）
- 指令：`lec run 課名 [--file F] [--model M] [--source S] [--set k=v]`、`lec stop [--force]`、`lec status --json`、`lec courses --json`、`lec config 課名`、`lec new 課名 [--from 範例]`、`lec devices --json [--test N] [--save N]`、`lec doctor --json [--mic]`、`lec summarize <資料夾> [--redo hh:mm:ss|all]`
- 同時只能一個 run/summarize（~/.local/state/lecture-notes/run.json：pid、session、course、mode）
- `<輸出資料夾>/status.json` 每 2 秒覆寫：phase（starting→loading→recording/transcribing→summarizing→finishing→done/failed/aborted）、mode、elapsed、transcribed、transcribe_lag、queue、sections_total、sections_summarized、llm_busy、llm_section、servers{whisper,llama}、errors、last_error、updated_at
- `events.jsonl`：phase / summary（label、status、topic、elapsed）/ error / stop_requested
- 輸出檔：transcript.md（即時追加）、transcript.srt、notes.md（追加；--redo 時由 notes.jsonl 重建）、notes.jsonl、config.used.toml、session.log、*-server.log、recording_*.ogg
- 停止：當時為 SIGINT 給 pid；**現在已改成 stop / stop_force 檔案機制**
- 設定寫入：`config.set_local()` 會重寫 local.toml（註解不保留）；課程檔 UI 可直接編 TOML
